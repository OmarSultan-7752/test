# حروف

مسابقة حروف لفريقين (خلايا سداسية، بنك أسئلة، مؤقت، تخريب).

## التشغيل
اللعبة ملفات ثابتة (HTML/CSS/JS) بدون سيرفر: افتح `index.html`، أو ارفع المجلد كما هو على أي استضافة ثابتة
(GitHub Pages، Netlify، Cloudflare Pages…).

> الجرس وجوالات اللاعبين يعتمدان على ميزة «الغرفة» داخل claude.ai فقط.
> خارجها تشتغل اللعبة كاملة على جهاز واحد، وزر الجرس يقول إنه غير متاح.

## الملفات
- `questions.js` / `questions_more.js` / `questions_hard.js`: بنوك الأسئلة
- `app.js`: منطق اللعبة، `bell.js`: الجرس، `style.css`: التصميم
- `python3 tools/build_artifact.py <out>`: يفحص الأسئلة ويجمع الصفحة في ملف واحد
